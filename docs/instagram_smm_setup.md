## A. Перейти Instagram з персонального на Бізнес-акаунт

Робити в **мобільному додатку Instagram** (у вебі обмежено).

1. Профіль клініки → меню (☰ зверху-справа) → **Налаштування і конфіденційність**
2. **Тип акаунта і інструменти** → **Перейти на бізнес-акаунт**
3. Категорія: **Ветеринар** (або Pet Service)
4. Заповнити контакти: телефон клініки, email, адреса (всі 3 — обов'язково для пізнішого API доступу)

## C. Зв'язати Instagram з Facebook Page

Без цього API «не побачить» Instagram. Це найважливіший крок.

**Спосіб 1 — через комп'ютер (рекомендую):**
1. **business.facebook.com** → **Налаштування** (зубчасте колесо у лівому нижньому куті)
2. **Облікові записи** → **Облікові записи Instagram**
3. **Додати** → ввести логін/пароль Instagram → підтвердити
4. **Підключити сторінку** → вибрати щойно створену FB-сторінку клініки

**Спосіб 2 — з мобільного:**
- Instagram → Налаштування → **Центр облікових записів** → **Облікові записи** → додати Facebook → вибрати сторінку клініки.

## D. Двофакторна автентифікація (Meta вимагає)

Без 2FA Meta App Review точно завернуть.

**На Instagram:**
1. Налаштування → **Безпека** → **Двофакторна автентифікація**
2. Вибрати: **Текстове повідомлення (SMS)** або **Authenticator-додаток** (Google Authenticator / Authy)
3. Підтвердити кодом

**На Facebook:**
1. Налаштування → **Безпека і вхід** → **Двофакторна автентифікація**
2. Той самий вибір: SMS або Authenticator
