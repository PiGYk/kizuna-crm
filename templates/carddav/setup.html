Контакти на телефон (CardDAV)

Що це?

Синхронізує всіх клієнтів CRM з адресною книгою телефону. Коли клієнт дзвонить — побачите ім'я і фото його тваринки прямо на екрані вхідного дзвінка.

2. Android (DAVx⁵)

  1. Встановіть DAVx⁵ з Google Play (безкоштовно) або з F-Droid.
  2. Відкрийте DAVx⁵ → натисніть + у правому нижньому куті.
  3. Оберіть "Login with URL and user name".
  4. Введіть:
    • URL: з поля вище
    • User name: з поля вище
    • Password: токен (НЕ пароль від CRM)
  5. Натисніть Login → знайде "Kizuna Clients" → ✓ оберіть.
  6. Account Name: Kizuna → Create.
  7. Перейдіть у Settings → Accounts → Kizuna → Account sync і ввімкніть Contacts ✓.
  8. Через 5-15 хвилин у Contacts з'явиться група "Kizuna" зі всіма клієнтами.

3. iPhone / iPad

  1. Settings → Contacts → Accounts → Add Account.
  2. Other → Add CardDAV Account.
  3. Server: {{ host }} · User Name: {{ username }} · Password: токен.
  4. Description: Kizuna → Next → Save.

4. Перевірка

Відкрийте Contacts app → побачите групу "Kizuna" з клієнтами. Подзвоніть з номеру одного з клієнтів — побачите ім'я і фото пацієнта на екрані виклику.
